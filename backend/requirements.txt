# Pinned to the exact versions this project is tested against.
#
# scikit-learn is pinned rather than ranged for a specific reason: the
# committed iceberg model in backend/models/ was trained with 1.6.1, and
# unpickling an estimator under a different scikit-learn version raises
# InconsistentVersionWarning, which the library documents as potentially
# producing invalid results. Pinning keeps the shipped model loading exactly
# as it was trained.
#
# If you retrain the model (python -m backend.ingestion.train_iceberg_model),
# bump this pin to the version you trained under; that version is recorded in
# backend/models/iceberg_model_meta.json.
#
# numpy is pinned because scikit-learn binary compatibility depends on it.
